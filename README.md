# The Houseplant Out-of-Office

A neglected fern files its out-of-office reply. It has not been watered since March, and from now on it is accepting sunlight only.

## How it works

`main.py` reads the single out-of-office line from `entry.txt` (resolved relative to the script itself, so it works from any working directory) and prints it to stdout. Standard library only, no dependencies, no network.
